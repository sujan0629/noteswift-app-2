# NoteSwift student client

Expo/React Native client for the NoteSwift learning-platform design. See the [repository overview](../README.md) for scope and backend requirements.

## Development

```bash
npm install
npm start
```

Configure a reachable backend using the [API setup guide](api/README.md). Use `npm run android`, `npm run ios`, or `npm run web` for the relevant target and `npm run lint` for the declared lint script.

The backend, teacher app, and admin app are not included in this public repository. Start with the [routed screens](app), [API clients](api), and [stores](stores) when reviewing the implementation.
